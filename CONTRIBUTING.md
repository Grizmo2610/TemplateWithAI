# Contributing to DataViz

## Before you start

Read `AGENTS.md`, `README.md`, and the relevant design files before making code changes.

## Branching

- Use a dedicated branch for each phase or feature.
- Do not commit directly to `main`.

## Code style

- Use English for names, comments, and docstrings.
- Use Google-style docstrings for all public functions and classes.
- Keep changes small and aligned with the design.

## Testing

- Run the relevant tests before committing.
- Do not commit broken code.

## Changelog

- Update `CHANGELOG.md` when a meaningful change is complete.
